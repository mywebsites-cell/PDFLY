# PDFLY

**PDFLY** is a free online PDF toolkit with 16 tools for everyday document tasks — no sign-up, no watermarks.

🌐 **Website:** [https://pdfly.live](https://pdfly.live)

## Tools

- Merge, split, rotate, reorder, and compress PDFs
- Convert between Word, Excel, images, and PDF
- Add watermarks, page numbers, and QR codes
- Lock and unlock PDFs with AES-256 encryption

## Features

- 100% free — no sign-up required
- No watermarks
- Fast in-browser and server-side processing
- Files processed privately and deleted automatically
