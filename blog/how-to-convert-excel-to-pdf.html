How to Convert Excel to PDF — Complete Guide (2026)

Published: January 25, 2026 • 7 min read

Converting Excel spreadsheets to PDF ensures your data looks identical for every recipient, regardless of whether they have Excel installed. PDFs lock in your formatting, prevent accidental editing, and are universally viewable. This guide covers four methods — from free online tools to Microsoft Excel's built-in exporter.

Why Convert Excel to PDF?

  • Universal compatibility: Recipients without Excel can view your spreadsheet on any device
  • Prevent editing: PDFs can't be accidentally modified unlike XLSX files
  • Lock in formatting: Fonts, colors, and column widths look identical for everyone
  • Professional reports: Financial statements and data reports look more polished as PDFs
  • Smaller file size: Complex spreadsheets often produce smaller PDFs than the original XLSX

Method 2: Microsoft Excel (Save As PDF)

If you have Microsoft Excel installed, it provides the best conversion quality — especially for complex spreadsheets with charts, pivot tables, and custom print areas.

Excel 2016, 2019, 2021, Microsoft 365:

  1. Open your spreadsheet in Excel
  2. Go to File ? Save As (or Export)
  3. Change "Save as type" to "PDF (*.pdf)"
  4. Click "Options" to configure what to include: Active Sheet, Entire Workbook, or Selection
  5. Check "Open file after publishing" if you want to preview immediately
  6. Click "Save"

Print Area Tips for Cleaner PDFs:

Before converting, set a print area so only your data columns are included — not empty columns that create extra white space:

  1. Select the data range you want in the PDF
  2. Go to Page Layout ? Print Area ? Set Print Area
  3. Then export to PDF as above

Pros: Best formatting fidelity, handles charts and pivot tables perfectly, can export multiple sheets
Cons: Requires a Microsoft 365 subscription ($7–$10/month)

Method 3: Google Sheets (Free Alternative)

If you don't have Microsoft Excel, Google Sheets is a free alternative that can open XLSX files and export them as PDFs.

How to Convert in Google Sheets:

  1. Go to Google Drive and upload your Excel file
  2. Double-click the file — Google Drive will open it in Sheets automatically
  3. In Google Sheets, go to File ? Download ? PDF Document (.pdf)
  4. A print settings dialog opens — configure page orientation, scaling, and margins
  5. Click "Export" — Google Sheets downloads the PDF

Pros: Completely free, cloud-based (works from any device), handles most Excel formats
Cons: Complex formatting (macros, advanced charts) may not convert perfectly; requires Google account

Method 4: LibreOffice Calc (Free Desktop App)

LibreOffice is a free, open-source office suite that excels at Excel-to-PDF conversion with excellent formatting fidelity.

Converting in LibreOffice Calc:

  1. Download and install LibreOffice from libreoffice.org (free)
  2. Open your Excel file in LibreOffice Calc
  3. Go to File ? Export as PDF
  4. In the PDF Options dialog, configure quality, page range, and security settings
  5. Click "Export" and choose a save location

LibreOffice even supports batch conversion via command line:

libreoffice --headless --convert-to pdf spreadsheet.xlsx

Common Excel to PDF Problems & Fixes

Columns are getting cut off in the PDF

This happens when your spreadsheet is wider than the page. Fix it by: (1) setting Print Area to only your data range, (2) going to Page Layout ? Fit to 1 page wide, or (3) changing page orientation to Landscape for wide spreadsheets.

The PDF has too many blank pages

This usually means your print area extends beyond your actual data. Select only your data range, set it as the Print Area (Page Layout ? Print Area ? Set Print Area), then convert again.

Charts look different in the PDF

For the best chart rendering, use Microsoft Excel or LibreOffice for conversion. Online tools render charts with reasonable accuracy, but complex 3D charts or custom chart types may differ slightly.

Tips for a Professional Excel PDF

  • Set print titles: In Excel, set "Rows to repeat at top" so column headers appear on every page of a multi-page PDF
  • Use Print Preview: Always preview before exporting to catch cut-off columns or formatting issues
  • Set page margins: Use 0.5" margins for data-dense spreadsheets to maximize usable page area
  • Freeze headers: For long spreadsheets, freeze the top row so it repeats on each PDF page
  • Lock formulas as values: If you don't want recipients to see your formulas, copy and Paste Special ? Values before converting
